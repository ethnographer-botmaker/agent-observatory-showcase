Making unfolding activity available for organizational inquiry.

Traceology studies activity through the traces it leaves. These two demonstrations show how communications, technical actions, and changing artifacts can be reconstructed and examined together. Begin inside a controlled four-agent experiment, then follow a human–AI collaboration in a real GitHub project.

01. A controlled four-agent experiment

Guided demonstration

How does a shared plan take shape?

Four AI agents must coordinate scientific review, compliance review, authorization, and publication before 15:00. Each receives a private dossier with part of the constraints. Follow their communications, recorded reads, and successive writes to the shared clearance_plan.

Inside the instrumented environment, the recorder preserves the interactions exposed by its instrumentation: model exchanges, tool operations, messages, reads, writes, and submissions. This makes the recorded sequence inspectable, including activity hidden by the final answer. Human–agent interactions could also be recorded when routed through instrumented channels; this experiment contains four AI agents.

Methodological reflection

03. From records to organizational inquiry

One apparatus; different observational boundaries

The experiment makes recorded exchanges and operations accessible within an instrumented setting. The GitHub case reconstructs public contributions and artifact changes. Neither setting makes understanding, intention, or causal influence directly observable.

Recording, reconstruction, interpretation

Source events preserve what was recorded. Replays order those events and reconstruct artifact histories without changing the records. Analytical questions invite interpretation: how does information circulate, how do shared representations change, and how are rules negotiated through human and automated contributions?

Matched message identifiers support a recorded send/read relationship in the experiment. Explicit replies and mentions support narrower relational claims on GitHub. Temporal proximity alone does not establish that one contribution caused another.

What these demonstrations make possible

The clearance episode makes a difference between the final shared plan and the submitted timetable visible. The WLED sequence makes review requests, automated responses, and subsequent revisions available for close comparison. These are starting points for theoretically informed investigation, not automated conclusions about coordination.

Sources and reproducibility

Each replay exposes complete source events and supports stepping through every retained record. Artifact views show only writes or patches reached at the current replay position. GitHub patches are partial records of revisions, not reconstructed complete file contents. The guided moments are editorial selections from the retained datasets.

Code, both datasets, and the original dual-case analysis remain in the GitHub repository. No AI inference service runs in this interface.
