Two lenses, shared provenance

The interaction lens follows recorded message reads in instrumented traces and explicit replies, mentions, or review requests in GitHub traces. Mentions are limited to accounts present in the trace; bare bot handles are mapped to matching bot accounts. The artifact lens follows recorded writes and available commit patches. Select any event to inspect its original fields.

What this does—and does not—show

These are deterministic views of retained records. They do not infer intentions, private reasoning, autonomous agency, or causal influence. GitHub comment bodies are retrospective snapshots; commit author dates are not necessarily publication times. No AI analysis service runs on this page.

Try your own data

JSON must contain a nonempty events array; JSONL contains one event per line. Each event needs unique event_id, increasing integer sequence_id, actor_id, and event_type. Generic traces support event and artifact inspection; directed ties require matching message IDs or explicit GitHub references. Uploads are validated structurally, not cryptographically audited.

Public import collects at most 100 items per endpoint and the first 10 commit details. Collection caps and missing data are reported with the case. Uploads are never sent to GitHub. Export your imported snapshot if you want to retain it.
