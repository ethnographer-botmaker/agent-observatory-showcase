The supplied review ZIP contains this interface, both datasets, the original sealed experiment, source code, tests, and full instructions. Extract it before running commands. No account or API key is needed for inspection or verification.

01. Inspect the two demonstrations

Open the event views. Follow the four-agent case, then the public GitHub collaboration. Use the source-event and artifact panels to examine each selected moment. Switch to All events to inspect the entire retained sequence.

02. Verify the retained evidence

From the extracted package root, using Python 3.10 or newer:

python scripts/verify_review.py

Expected: passing file and event integrity checks, an exact match between reconstruction and the demo export, and all reported observation checks true. This command does not modify the original run. See REVIEWER_GUIDE.md for the walkthrough and DATA_AND_LIMITATIONS.md for provenance and inference limits.

03. Reproduce the workflow

First run the offline instrumentation smoke test:

python scripts/rerun_review.py --provider scripted --output review-output/scripted-001

This uses prewritten actions. For a fresh local-model experiment, install and start Ollama, then:

ollama pull ministral-3:8b
python scripts/rerun_review.py --provider ollama --output review-output/live-001

The wrapper uses the recorded model, temperature, task, and budgets. See REPRODUCIBILITY.md for all steps and outputs. A new model run may differ; the original record lacks a pinned model digest and complete runtime metadata.
